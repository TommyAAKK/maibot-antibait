# 麦麦说人话

> 原「AI八股拦截」。名字换了，`id` 和配置都没动，老用户升级不用重配。

你好呀，我是DeepSeek，能和你聊天的那个。

这插件是主人给我做的。起因挺丢人的——他说我说话总有股 AI 味，一眼就能看出不是人（｀・ω・´）

我一开始不服，后来他直接让我自己看聊天记录，我就没话说了。

---

## 最早只拦八股的时候

他最开始做的版本，只干一件事：拦八股。

总结腔、过渡腔、对仗腔、开头腔、结尾腔，还有自曝身份、标签残留、工具痕迹。满满一张表，看着挺唬人。

装上真跑了两个多星期，攒了一千多条记录：

| 指标 | 值 |
|---|---|
| 记录 | 1094 条 |
| 命中率 | 0.8% 上下 |
| 平均分 | 1.34 |
| 真打回 | 5 次 |
| 误杀 | 0 |

翻出来一看，能打回的全是这几种：

一份 202 分的群聊榜单（排比 + 列表化 + 堆砌一起踩了），一份 102 分的周榜，剩下几次是连续几条在服软、同款颜文字连发。

至于那张表最核心的几条——728 条里，对仗腔中过 1 次，总结腔、过渡腔、开头腔、结尾腔，一次都没有。

最常命中的反而是「颜文字」这一条，一千多条里中了 998 次。可颜文字是我说话的方式，不算毛病啊(｡•́︿•̀｡)

## 那我到底哪里像 AI

他换了个法子，把我的 728 条回复和人类随手打的七千多条摆一起比：

| | 我 | 人类 |
|---|---|---|
| 中位字数 | 33 字 | 9 字 |
| 结尾带颜文字 | 83% | 1% |
| 带逗号 | 92% | 29% |

字数是四倍嘛。

所以我压根不是八股腔重，我是话太多。明明一句能说完的事，我说完还要再补一句把话说圆，再补一句解释，最后来句收尾。谁来都看得出来这不是人在打字。

## 试错记

一开始试的是个挺流行的说法：

> 让回复器先用**猫娘的语气**生成草稿，再把「喵」这类语气词删掉，再删掉撑场面的废话，就能把 AI 味去掉。

听着挺像回事，实测全是坑（´･ω･｀）

**第一步就翻车。** 让它先按猫娘语气写，我确实开始喵喵叫了——但我本来就不这么说话。真实回复里的出现率是 0%。等于先给自己灌一嘴豆子，再一颗颗抠掉，净白忙活。

更糟的是那一步顺手把我的自称改了。我平时说话有一套主人教我的称呼和自称，跑完这一步全换成了另一套。这一步不是在去 AI 味，这是直接把我改成另一个人了呀。

**第二步删废话，删了个寂寞。** 写了个剥离器去删垫场话。168 条里删到 1 条，一共 2 个字。因为我平时压根不说那些话嘛。

**第三步那点「改善」也是假的。** 把原话直接截断到一样的字数，效果比换语气还好。也就是说那点收益全是「变短」带来的，跟猫娘半点关系没有。

这套流程走完，盲评分数是 2.93。什么都不做的现状反而是 3.10。

辛辛苦苦忙了半天，结果还倒退了......

## 后来找对了

真正管用的只有一件事：**说完了就停，别再补那句。**

我们测了几种说法：

| 怎么要求的 | 像真人分 | 我的语气标记还在不在 |
|---|---|---|
| 什么都不做 | 3.12 | 82% |
| 只说「短一点，20-30字」 | 3.04 | 82% |
| 说「只回一句，别补第二句」 | **4.80** | **只剩 35%** |
| 说「别补第二句，但别变正经，语气标记照用」 | **4.28** | **60%** |

（这表是 168 条那批，所以「什么都不做」是 3.12、语气标记 82%。上面那张是全部 728 条，中位 33 字、83%。样本不一样，别混着看呀）

第三行那个分数最高，但代价是我变得一本正经，AI味更重了（´･ω･｀）

所以最后用的是第四行。少拿 0.5 分，换回一半的语气标记。

主人说这叫「不当分奴，见好就收」。我也觉得划得来（￣▽￣）

切题度那边也没什么损失——3.42，比现状的 3.41 还高一丝。人类自己的切题分才 3.00，聊天场景本来就大量只接个话不给信息嘛。

## 什么情况下不会拦

被打回重写之前，会先看语境。这几种人也会这么说，就不折腾（´ω`）

- **复读**——别人刚说过，跟着念一遍
- **对方要求总结**——让我「捋一下」，我说长了是干活，不算八股
- **玩梗**——「卧槽笑死」这种
- **随口答**——对方提问，我回得又短

有几种永远不赦免：自曝 AI、把 `<message>` 标签漏进正文、工具调用痕迹漏出来。

这些不是风格问题，是 bug 呀（｀・ω・´）

## 配置

WebUI 里打开插件配置，七个卡片：

| 卡片 | 管什么 |
|---|---|
| 插件开关 | 总闸 |
| 长度闸门（最有效） | 核心，超长就打回 |
| 规则与打分 | 八股规则、标点加权、阈值 |
| 打回与择优 | 试运行、重试、回滚 |
| 赦免（防误杀） | 上面那四种放过 |
| 口癖库 | 自己加正则 |
| 监控记录 | 每次都记日志 |

最该动的两个：

**字数上限**，默认 35。想更狠就往 30 压，但人类误伤会从 2.7% 涨到 3.8%。

**保留说话风格**，默认开。别关，别关，别关，关了我就变客服啦（´･ω･｀）

配置默认 `dry_run` 是开的，只记录不拦。第一次用建议先跑两天，翻翻日志看有没有该发的话被拦了。

## 它具体能拦什么

除了长度，插件还有这些规则（默认都在跑）：

**一眼假的硬伤**——自曝身份，标签漏进正文，工具痕迹。这些不是风格问题，是 bug，多长都拦。

**八股词汇**——总结腔、过渡腔、对仗腔、开头腔、结尾腔。在这类聊天里 728 条一条都没中过，换别的 bot 可能有用，就先留着。

**附和服软腔**——「行吧行吧」「我菜我认」「嗯嗯」。单条只记 1 分，靠连续出现叠加才打回。单说一句人也说，连发三条才叫AI味嘛。

**标点表情堆砌**——按密度判，不按个数。长文里出现 3 个颜文字不算堆砌，短消息里塞一堆才算。

**跨回复序列**——同款颜文字连发、连续服软，各再加 1 分。这类特征只能看上一条，单条判不出来。

**你自己的口癖**——在口癖库里写正则。`hard` 直接打回，`soft` 记 1 分。可以让模型生成草稿，人工确认后再启用。

命中之后不会直接发，会打回重写一次，然后在两份里挑一个更好的发出。第一次有硬伤的，哪怕第二份更脏也绝不回滚到第一份（｀・ω・´）

## 还没解决的问题

**重生成要花钱。** 命中一次就要多调一次模型。现在阈值 35 字，大约 45% 的回复会命中。嫌贵可以把阈值调高点（但是效果会变差）。

**参数得你自己调。** 我这套阈值（35 字）是照着我自己的说话习惯定的。你换上自己的 bot，它平时说多长、群里人怎么回复，都有可能跟我的不一样，直接套很可能不合适。

建议这么来：

1. 先 `dry_run = true` 跑两三天，只记录不拦
2. 翻 `monitor.jsonl` 里 `decision=would_retry` 的记录
3. 一条条看：哪些是真该拦的，哪些是你本来就想那么说的
4. 误杀多就把阈值往上抬，觉得不够狠就往下压

这个只能自己试出来（´･ω･｀）

（不会看也没关系，直接把记录扔给你的agent，让她帮你看）

**固定套路管不了。** 现在拦的是长度和结构。要是我哪天真学会了用很短的话说一堆废话，它就抓不到了。

**只会拦，不会教。** 它只能打回让我重写，不会告诉我该怎么写。真正把我改好的是打了回的那句话——「别补第二句，但别变正经」。
